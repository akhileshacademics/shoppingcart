# Simple Shopping Cart

A responsive one-page shopping cart using HTML, CSS, TypeScript, Node.js, and Express.

## Run locally

```bash
npm install
npm run build
npm start
```

Open `http://localhost:3000`.

Use the promo code `SAVE10` to test the discount.

Edit the TypeScript source in `src/app.ts`. Run `npm run build` after making TypeScript changes; it creates the browser file at `public/js/app.js`.
